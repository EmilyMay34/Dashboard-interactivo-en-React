##  Descripción del Proyecto
Este proyecto analiza el catálogo de **Netflix Movies and TV Shows** (obtenido de [Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)) dentro del contexto de **Negocios y Cultura Digital**. El objetivo principal es examinar las tendencias globales de producción, la evolución de estrenos a lo largo del tiempo, los géneros más populares y su distribución geográfica para comprender cómo varían los hábitos de consumo de entretenimiento digital por región y año.
